# poria-common-feign 部署与配置

## 模块作用与部署

服务间 HTTP 客户端库，不独立运行，不监听额外端口。提供 OpenFeign、OkHttp 配置和 EnablePlatFeignClients 注解。需要部署的是客户端实际调用的目标服务。

## 配置什么及作用

| 项目 | 作用与要求 |
|---|---|
| 调用服务的 URL | 使用各 @FeignClient 的 url 定义；常用 PORIA_UPMS、PORIA_auth 等见 [core](../poria-common-core/部署与配置.md) |
| 客户端注册与包扫描 | 使用 Spring Feign 客户端注册机制；只有接口定义、没有注册并不能发起调用 |
| FeignConfig | 提供 OkHttp Client Bean，需确保配置类被宿主应用加载 |
| spring.cloud.openfeign.client.config.default.connectTimeout | 标准 OpenFeign 连接超时覆盖项，单位毫秒；当前仓库未显式设置 |
| spring.cloud.openfeign.client.config.default.readTimeout | 标准 OpenFeign 读取超时覆盖项，单位毫秒；当前仓库未显式设置 |

超时也可按客户端名称单独配置，部署值按业务耗时确定。内部调用、平台 Token 透传等认证处理在 security 模块，不能假定所有调用都是匿名可访问的。

当前客户端多用固定 URL，未见必须部署注册中心的配置。业务错误结果仍需由调用方检查，定时任务可使用 JobExecution.requireSuccess。MySQL、Redis 无需在本文配置，本文未实际请求目标服务。

## 宿主服务参数示例

以下是可增加的标准 OpenFeign 超时覆盖项，当前源码未显式设置；这里只示例连接 3 秒、读取 15 秒，实际值按业务调整。

```yaml
spring:
  cloud:
    openfeign:
      client:
        config:
          default:
            connectTimeout: 3000
            readTimeout: 15000
```

目标地址按客户端分别提供，例如 PORIA_UPMS=http://<UPMS服务地址>:4000。没有对应客户端时无需为本模块配置所有业务服务。
