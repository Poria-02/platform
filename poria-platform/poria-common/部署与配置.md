# poria-common 部署与配置

## 模块作用与部署

Maven 公共依赖聚合模块，不启动独立服务、不监听端口。各业务应用按需要引入下面的子模块。MySQL、Redis 部署和连接配置不在本文范围。

| 子模块 | 作用 | 需要额外部署什么 |
|---|---|---|
| [bom](poria-common-bom/部署与配置.md) | 统一依赖版本 | 无 |
| [core](poria-common-core/部署与配置.md) | 基础工具、统一返回、公共配置和请求锁 | 无独立服务；完整追踪另需 Agent、OAP |
| [data](poria-common-data/部署与配置.md) | MyBatis-Plus、字段填充、转换和数据权限 | 相关功能需要能访问 UPMS |
| [feign](poria-common-feign/部署与配置.md) | HTTP 服务客户端 | 被调用的业务服务 |
| [security](poria-common-security/部署与配置.md) | 认证授权、内部接口检查、XSS 处理 | 平台认证等业务服务 |
| [swagger](poria-common-swagger/部署与配置.md) | 接口文档辅助 | 无独立 Swagger 服务 |
| [gateway](poria-common-gateway/部署与配置.md) | 动态路由基础组件 | 运行 poria-gateway 应用 |
| [log](poria-common-log/部署与配置.md) | 日志、TraceId 和可选 Kafka 投递 | 启用日志投递时需要 Kafka；追踪另需 SkyWalking |
| [seata](poria-common-seata/部署与配置.md) | 分布式事务客户端接入 | 使用时需要 Seata Server |
| [excel](poria-common-excel/部署与配置.md) | Excel 导入导出 | 无独立服务 |
| [kafka](poria-common-kafka/部署与配置.md) | 消息生产者和发送工具 | 使用时需要 Kafka Broker |

## 配置在哪里

配置在使用它们的宿主业务应用中生效。公共包提供的 application.yml 不应被默认认为已与应用同名文件完整合并；实际需要的配置应在宿主服务中明确提供或导入。

application-log.yml、application-kafka.yml 对应 log、kafka profile；启用前先准备相应服务与参数。Seata 通过配置类显式加载 seata-config.yml。具体开关、地址和配置用途见对应子模块说明。

Java 库依赖不等于已部署中间件。本文未启动任何外部组件。
