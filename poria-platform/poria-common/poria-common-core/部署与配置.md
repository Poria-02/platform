# poria-common-core 部署与配置

## 模块作用与部署

公共 Java 依赖库，不独立运行。提供 R 返回结构、异常、JSON 与 MVC 配置、RestTemplate、服务地址常量、请求锁和 Trace 工具等。由宿主服务引入，使用宿主服务端口。

## 配置什么及作用

服务地址定义在 [ServiceNameConstants](src/main/java/cn/poria/common/core/constant/ServiceNameConstants.java)。按实际调用需要配置：

| 环境变量 | 默认地址与用途 |
|---|---|
| PORIA_UPMS | http://poria-upms:4000，用户、角色、部门、字典等调用 |
| PORIA_auth | http://poria-auth:3000，认证服务；源码大小写如此 |
| PORIA_BASE | http://poria-base:8009，基础服务，只有读取该常量的调用才会使用 |
| PORIA_MESSAGE | http://poria-message:8007，预留消息地址，不能覆盖业务代码中写死的 URL |
| PORIA_LOG | http://poria-log:8046，预留日志地址；仓库不包含独立 poria-log 服务 |

这些主机名需由运行网络实际解析。常量中的占位符需要调用方通过 Spring 等机制解析，直接当普通字符串用于 HTTP 请求不会自动替换。

@RequestLock 在方法上配置 key、waitTime、leaseTime，分别控制锁标识、等待秒数与租约秒数。它是并发互斥工具，不等于业务幂等。默认等待 1 秒、租约 180 秒。

## 外部组件

基础工具没有专属外部服务；缓存与锁的连接配置按要求不展开。完整 SkyWalking 追踪还需实际加载 Agent 并配置 OAP，依赖 apm-toolkit-trace 本身不能完成部署。RestTemplate 当前没有在配置类中显式设置请求超时，使用方需按业务要求配置。

本文未调用远程接口。

## 调用方地址参数示例

此模块没有独立部署参数。使用对应客户端的宿主进程按需设置环境变量；这不是需要全部部署的服务清单：

```dotenv
PORIA_UPMS=http://<UPMS服务地址>:4000
PORIA_auth=http://<认证服务地址>:3000
PORIA_BASE=http://<base服务地址>:8009
```

消息和独立日志服务是预留地址，不使用对应调用时无需填写。缓存和锁的连接参数按要求不展示。
