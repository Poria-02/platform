# poria-common-excel 部署与配置

## 模块作用与部署

Excel 导入导出依赖库，不独立运行，不需要 Excel 服务器或安装 Microsoft Excel。由 Spring MVC 业务应用引入，提供参数读取、返回值导出和模板处理。

## 配置什么及作用

| 配置或注解 | 作用 |
|---|---|
| excel.template-path | 模板资源目录，默认 excel，需将对应模板放入应用资源中 |
| @RequestExcel.fileName | 上传参数名，默认 file |
| @RequestExcel.headRowNumber | 导入标题行数，默认 1 |
| @RequestExcel.readListener | 导入读取及校验处理器 |
| @RequestExcel.ignoreEmptyRow | 是否忽略空行，当前默认 false |
| @ResponseExcel.name、suffix、sheets | 下载文件名、格式和 Sheet |
| @ResponseExcel.template | 使用的模板 |
| @ResponseExcel.include、exclude、converter、writeHandler | 输出字段、转换和样式处理 |

来源：[ExcelConfigProperties](src/main/java/cn/poria/common/excel/config/ExcelConfigProperties.java) 和 annotation 目录。

宿主服务还需提供业务接口、权限、上传大小限制和业务校验。该配置依赖 MVC 的 RequestMappingHandlerAdapter，不是响应式网关中的独立导入服务。

MySQL、Redis 无需在本文配置，本文未生成或导入表格。

## 宿主服务参数示例

```yaml
excel:
  template-path: excel
```

模板路径默认是 excel，使用模板导出时放入相应资源文件；不使用模板时可保持默认，不需要新部署程序。
