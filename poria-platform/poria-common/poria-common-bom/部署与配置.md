# poria-common-bom 部署与配置

## 模块作用与部署

Maven BOM，集中管理公共模块与第三方库版本。没有应用启动类、HTTP 端口或独立部署进程。

## 配置什么及作用

配置文件：[pom.xml](pom.xml)。

| 配置 | 作用 |
|---|---|
| poria.version | 公共模块版本 |
| mybatis-plus.version、hutool.version、redisson.version | 对应 Java 依赖版本 |
| springdoc.version | OpenAPI 相关依赖版本 |
| xxl-job.version | XXL-Job 执行器依赖版本，当前 2.3.1 |
| aws.version | base 使用的 AWS S3 SDK 依赖版本 |
| dependencyManagement | 为引用方统一依赖版本，不会自动引入或运行所有依赖 |

MySQL、Redis 的部署和连接配置不展开。某个版本属性存在不代表它被所有模块使用，模块自己写明版本时以实际 Maven 解析结果为准；例如 Seata starter 在自己的 POM 中明确指定版本。

配置变更影响构建依赖，不会自动修改已经运行的服务或外部中间件。本文未构建项目或检查版本兼容性。
