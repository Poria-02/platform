# poria-gateway 部署与配置

## 模块作用与部署

独立运行的响应式网关，默认 HTTP 端口 9999，需要 Java 21。负责统一接口入口、图片验证码、动态路由、请求头清洗及部分请求过滤。需要从网关环境访问实际的 auth、UPMS、base 等服务。

配置文件：[application.yml](src/main/resources/application.yml)。不要求另行部署一个名为 poria-common-gateway 的服务。

## 需要配置什么

| 配置 | 作用与要求 |
|---|---|
| server.port | 网关端口，默认 9999 |
| spring.main.web-application-type | 当前为 reactive，使用 WebFlux 网关 |
| spring.application.name、spring.profiles.active | 应用标识和运行环境 |
| 动态路由的 URI、Path 和 filters | 在平台路由管理中维护实际服务地址、匹配前缀和过滤器；运行网关本身不会凭空生成正确路由 |
| spring.cloud.gateway.server.webflux.globalcors | 配置允许的前端来源、方法、请求头和 Cookie；当前较宽泛，部署时按实际页面域名配置 |
| spring.http.codecs.max-in-memory-size | 网关编解码缓冲区上限，当前 100MB；不是后端服务的单文件上传上限 |
| sync-encrypt-key / SYNC_ENCRYPT_KEY | 自定义同步报文加解密密钥，配合 isEncrypt 请求头使用，需与调用端一致 |
| gateway.encodeKey | PasswordDecoderFilter 使用的密钥；该配置目前未列入 YAML，只有实际给路由启用此过滤器时才需要按对应协议配置 |
| springdoc.api-docs.enabled / SWAGGER_API_DOCS_ENABLE | 网关 OpenAPI 描述开关 |
| springdoc.swagger-ui.enabled / SWAGGER_ENABLE | 文档 UI 开关 |
| springdoc.api-docs.path | OpenAPI 描述接口路径；当前写成 /swagger-ui.html，但此配置本身定义的是描述接口，不是 UI 页面 |
| logging.level.cn.poria.gateway.filter | 网关过滤器日志级别 |

## 功能边界

全局路由过滤器会移除第一个服务路径段，例如 /auth/plat/login 转发为认证服务的 /plat/login，路由与前端调用前缀应相互匹配。

RateLimiterConfiguration 仅提供限流 KeyResolver，还需要路由配置 RequestRateLimiter 才会执行对应限流。当前 Spring servlet multipart 配置不应作为响应式网关的唯一上传限制依据，业务服务仍需配置自身限制。

自定义登录解密过滤器和 auth 登录解密应按实际协议配置，避免重复解密。完整追踪、Kafka 日志是可选能力，见 [公共日志](../poria-common/poria-common-log/部署与配置.md)。

MySQL、Redis 配置不在本文范围，本文未实际验证路由。

## 部署参数示例

替换前端来源域名、密钥；路由目标地址另外在平台路由管理中填写。以下不是已经写回源码的配置。

```yaml
server:
  port: 9999
spring:
  application:
    name: poria-gateway
  profiles:
    active: prod
  main:
    web-application-type: reactive
  http:
    codecs:
      max-in-memory-size: 100MB
  cloud:
    gateway:
      server:
        webflux:
          globalcors:
            cors-configurations:
              '[/**]':
                allowed-origin-patterns:
                  - 'https://<管理平台域名>'
                allowed-methods: [GET, POST, PUT, DELETE, PATCH, OPTIONS]
                allowed-headers: '*'
                allow-credentials: true
                exposed-headers: 'Content-Disposition,Content-Type,Cache-Control'
sync-encrypt-key: '<调用端一致的AES密钥>'
springdoc:
  api-docs:
    enabled: false
  swagger-ui:
    enabled: false
logging:
  level:
    cn.poria.gateway.filter: info
```

网关路由的部署值：/auth/** 指向认证服务 3000，/upms/** 指向 UPMS 4000，/base/** 指向 base 8009；实际 Path、URI 和过滤器按现有路由记录设置。没有启用 PasswordDecoderFilter 时，不需要为它额外填密钥。
