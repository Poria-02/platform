# 部署与配置总览

本说明覆盖全部 Maven 模块和 Vue 前端，说明需要运行什么、配置什么以及各配置的作用。MySQL、Redis 的部署与连接配置按要求不展开。以下状态依据当前源码，不代表已完成运行验证。

## 需要独立运行的服务

所有后端应用使用 Java 21。端口为当前源码默认值，调整后需同步修改调用地址和网关路由。

| 模块 | 默认端口 | 作用 | 详细说明 |
|---|---|---|---|
| poria-auth | 3000 | 登录、令牌签发与刷新 | [认证](poria-auth/部署与配置.md) |
| poria-gateway | 9999 | 统一接口入口、验证码和路由转发 | [网关](poria-gateway/部署与配置.md) |
| poria-upms-biz | 4000 | 用户、角色、菜单、部门和系统配置 | [UPMS](poria-upms/部署与配置.md) |
| poria-base-biz | 8009 | 文件、Banner、版本等基础能力 | [base](poria-base/部署与配置.md) |
| poria-job | 5002 | XXL-Job 执行器应用 | [定时任务](poria-job/部署与配置.md) |
| Vue 前端 | 开发 8000；生产由站点服务器决定 | 管理平台界面 | [前端](../vue/部署与配置.md) |

任务执行器另外监听 9999，和网关同机时会冲突；建议将 xxl.job.executor.port 配为 9998。XXL-Job Admin 是单独的控制台，前端界面示例使用 9080。

## 按功能准备的外部组件

| 功能 | 需要准备什么 | 是否必须 |
|---|---|---|
| 文件上传 | 可访问的 S3 兼容存储、存储桶及访问凭据 | 使用 base 文件能力时需要；当前 base 启动也会创建 OSS 客户端 |
| 音频转换 | base 运行环境内的 FFmpeg 可执行文件和可写临时目录 | 上传需转换的音频时需要 |
| 定时任务 | XXL-Job Admin、poria-job、实际任务方法 | 使用定时调度时需要 |
| REBUILD 登录对接 | 已运行的目标系统、地址及账号、应用凭据 | 使用该对接接口时需要 |
| 短信发送 | 短信消息服务；本仓库没有 poria-message 实现 | 使用 UPMS 短信发送时需要 |
| Kafka 消息或日志投递 | Kafka Broker、主题及相匹配的认证配置 | 启用 kafka 或 log 对应能力时需要 |
| 分布式事务 | Seata Server、事务分组及业务事务接入 | 引入并实际使用 Seata 时需要 |
| 链路追踪 | SkyWalking Agent、OAP 及所需查看界面 | 使用完整链路追踪时需要；依赖包不会自动部署这些组件 |

基础登录和管理界面不要求先部署所有可选组件。当前服务调用主要使用固定 URL，未发现必须部署 Nacos、Eureka、Sentinel 的接入配置。

## 聚合模块和依赖库

以下模块不独立监听端口：

- [poria-upms](poria-upms/部署与配置.md)：聚合 UPMS API 和业务服务。

- [poria-base](poria-base/部署与配置.md)：聚合 base API 和业务服务。

## 通用配置的含义

| 配置 | 作用 |
|---|---|
| server.port | 运行应用的 HTTP 端口 |
| spring.application.name | 应用标识，供日志及组件识别 |
| spring.profiles.active | 选择 dev、prod 等运行配置 |
| spring.profiles.include | 额外加载 log、kafka 等配置；仅配置文件存在并被加载时生效 |
| springdoc.api-docs.enabled | 开启或关闭 OpenAPI 接口描述 |
| logging.level.* | 各包的日志级别 |

配置中的 ${变量名:默认值} 表示优先读取变量，缺省使用默认值；冒号后为空则缺省为空字符串。@artifactId@ 和 @profiles.active@ 是 Maven 构建过滤占位符，不是环境变量。

服务地址必须从调用方所在环境可达。poria-auth、poria-upms 等默认主机名需要相应的 DNS 或容器网络支持，不能默认认为 Linux 主机可解析。密钥与账号填真实环境值，本文不复制仓库内的凭据。

本文提供配置说明，不包含安装、启动或重启操作。
