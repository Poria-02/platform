# poria-job 部署与配置

## 模块作用与部署

独立运行的 XXL-Job 执行器，需要 Java 21。它接收调度请求并执行 Java 任务；任务配置界面属于另外部署的 XXL-Job Admin。

| 组件 | 端口与要求 |
|---|---|
| poria-job 应用 | server.port 默认 5002 |
| 执行器通信 | xxl.job.executor.port 当前默认 9999；与网关同机时建议改为 9998 |
| XXL-Job Admin | 界面地址示例使用 9080；官方 Docker 镜像内部端口为 8080 |

当前 xxl-job-core 实际依赖为 2.3.1，Admin 使用匹配版本。当前仓库没有实际 @XxlJob 任务方法，配置好执行器还需补充业务任务。

配置文件：[application.yml](src/main/resources/application.yml)。

## 需要配置什么

| 配置 / 环境变量 | 作用与要求 |
|---|---|
| xxl.job.admin.addresses / XXL_HOST、XXL_PORT | Admin 地址，需包含 /xxl-job-admin；执行器必须能访问 |
| xxl.job.accessToken | 执行器与 Admin 共用的通信凭据，双方一致；当前源码为固定值，应按部署环境覆盖 |
| xxl.job.executor.appname | 执行器分组 AppName，当前是示例名称，需与 Admin 中完全一致 |
| xxl.job.executor.address | 对外注册的执行器地址，必须从 Admin 环境可达 |
| xxl.job.executor.ip | 执行器注册 IP；容器或多网卡环境按实际可达地址配置 |
| xxl.job.executor.port | 接收调度的通信端口，不是应用 5002 端口 |
| xxl.job.executor.logpath | 任务日志目录，当前 /data/applogs/xxl-job/jobhandler，运行账号需要写权限 |
| xxl.job.executor.logretentiondays | 任务日志保留天数，当前 30 |
| spring.profiles.active、springdoc.api-docs.enabled | 运行环境和 OpenAPI 开关 |

## 业务与界面配置

Admin 中还需设置 JobHandler 名称、Cron、参数、超时及重试；JobHandler 与 @XxlJob 的值一致。JobExecution.requireSuccess 可检查远程业务返回结果并在失败时抛出异常，任务仍需设计重复执行保护。

前端唯一的界面地址是 VITE_XXL_JOB_ADMIN_URL，指向 Admin，不能指向执行器。平台登录与 Admin 登录分别处理。

官方 SQL 获取位置和端口对照保留在 [XXL-Job 端口与 SQL 说明](XXL-Job-Docker-部署指南.md)。MySQL、Redis 部署和连接配置不在本文范围；本文未触发任务。

## 执行器部署参数示例

部署 poria-job 时明确提供如下值，IP、Token 必须替换；Admin 中创建 AppName 为 poria-job 的执行器分组。

```yaml
server:
  port: 5002
spring:
  application:
    name: poria-job
  profiles:
    active: prod
xxl:
  job:
    accessToken: '<与Admin相同的通信Token>'
    admin:
      addresses: 'http://<Admin服务地址>:9080/xxl-job-admin'
    executor:
      appname: poria-job
      address: 'http://<Admin可达的执行器IP>:9998/'
      ip: '<Admin可达的执行器IP>'
      port: 9998
      logpath: /data/applogs/xxl-job/jobhandler
      logretentiondays: 30
springdoc:
  api-docs:
    enabled: false
```

9998 是部署建议值，源码默认仍是 9999。Admin 侧的 xxl.job.accessToken 必须与上面一致；Admin 对外端口示例为 9080，容器内为 8080。Admin 需能访问执行器的 address，执行器也需能访问 Admin。

前端界面参数：

```dotenv
VITE_XXL_JOB_ADMIN_URL=http://<Admin服务地址>:9080/xxl-job-admin/
```
